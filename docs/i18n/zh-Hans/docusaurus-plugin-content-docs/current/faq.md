# 常见问题

### Qoderian 支持移动端吗？

不支持。Qoderian 仅支持桌面端（macOS、Linux、Windows），因为它要运行本地 Qoder CLI，需要完整的文件系统和 shell 权限。

### Qoderian 需要 API key 吗？

不需要。登录完全由本地 Qoder CLI（`qodercli login`）管理；插件不会索要 API key。

### 环境要求是什么？

Obsidian v1.7.2+，以及同一台机器上已登录的 Qoder CLI。暂不支持 Windows arm64。

### 智能体在哪里工作？

在你的仓库（vault）里。仓库就是智能体的工作目录，文件读写、检索、bash 和多步工作流都开箱即用。

### 如何报告问题或提功能建议？

请在 [GitHub](https://github.com/QoderAI/qoderian/issues) 上提 issue。
