# Code of Conduct

Qoderian contributors are expected to keep project spaces welcoming,
professional, and focused on constructive collaboration.

Be respectful, assume good intent, give actionable technical feedback, and
avoid harassment, discrimination, personal attacks, or publication of another
person's private information. Maintainers may edit or remove contributions and
restrict participation when behavior harms the community.

Report conduct concerns privately to the repository maintainers. Do not use a
public issue when the report contains personal or sensitive information.
